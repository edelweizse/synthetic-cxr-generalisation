# Data: sources, access, restrictions and an anonymised example

No real images from any dataset are included in this repository. All three datasets are public research datasets obtained from their providers.

## Sources and how to obtain them

| Dataset | Role | Size used | Licence / access | How to obtain | Where it goes |
|---|---|---|---|---|---|
| **Kermany** (Guangzhou paediatric chest X-rays; Kermany et al., 2018) | study-1 source: train / validation / internal test | 5,856 images | CC BY 4.0, open | Kaggle: <https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia> | `data/kaggle/chest_xray/{train,val,test}/{NORMAL,PNEUMONIA}/*.jpeg` |
| **RSNA Pneumonia Detection Challenge** (NIH ChestX-ray14 subset with adjudicated labels; Shih et al., 2019) | **external test only**, split by patient hash into RSNA-dev (30 %) and RSNA-test (70 %) | 29,684 labelled studies | RSNA challenge terms, registration on Kaggle / RSNA | <https://www.rsna.org/rsnai/ai-image-challenge/rsna-pneumonia-detection-challenge-2018> (DICOM images) + MD.ai adjudicated label export | `data/rsna/…/*.dcm`, `data/pneumonia-challenge-annotations-adjudicated-kaggle_2018.json` |
| **CheXpert Plus** (Stanford; Irvin et al., 2019) | study-2 source and generator training set | 11,969 frontal images for classifiers (one per patient), 9,968–29,538 for generators | **restricted** (see below) | accept the Stanford AIMI research-use agreement, then download through Redivis with your own account: `python scripts/chexpert/fetch.py meta`, `select`, `images` | `data/chexpert/` |

## Restricted data (CheXpert): access limits

* CheXpert is available only to individuals who accept the **Stanford AIMI research-use agreement**; it may not be redistributed. Every user must request access and download it with their own account.
* This repository therefore contains **no CheXpert images**. It contains derived, de-identified metadata needed to reproduce the exact splits (`artifacts/manifests/chexpert*.csv`: dataset image path, the dataset's own de-identified patient ID, age, sex, view, label, split) and the card of a classifier trained on CheXpert (`models/CX_E2_ERASE_efficientnet_b0/card.json`; weights only in the submission archive). These are shared with the instructor for grading, not published.
* Kermany is open (CC BY 4.0). RSNA images are used only as an external test set and are not redistributed, except the six demo examples in `app/examples/` (3 Kermany test images, 3 RSNA images, already de-identified by the providers).

## Anonymised example (shareable)

Real CheXpert images cannot be shared. As a permitted example of what the CheXpert data looks like to our pipeline, `docs/data_examples/` contains four images **generated by our CheXpert-trained generator** (v2, guidance 2.5). They depict no real patient; the nearest-neighbour check found no synthetic image closer to a training image than two different real patients are (0 of 10,000).

| File | Prompt |
|---|---|
| `synthetic_normal_1.png`, `synthetic_normal_2.png` | "a frontal cxr_scan of normal lungs, clear lung fields, radiograph" |
| `synthetic_pneumonia_1.png`, `synthetic_pneumonia_2.png` | "a frontal cxr_scan showing pneumonia, lung consolidation, radiograph" |

Manifest format (one row per image; the values below are illustrative, not a real record):

| column | example | meaning |
|---|---|---|
| `image_id` | `C/patientXXXXX` | unique id (C = CheXpert) |
| `image_path` | `data/chexpert/images/patientXXXXX/study1/view1_frontal.png` | local path after download |
| `label` | `1` | 1 = lung opacity / pneumonia / consolidation, 0 = no finding |
| `source` | `chexpert` | dataset |
| `patient_id` | `patientXXXXX` | the dataset's de-identified patient id (splits are by patient) |
| `view` | `AP` | AP or PA frontal film |
| `age`, `sex` | `60`, `Female` | from the dataset metadata, used for subgroup analysis |
| `split` | `train` | train / val / test |
| `subset_rank` | `1200` | class-balanced nested subset order (first *k* per class = training subset of size 2*k*) |

## Personal data and secrets

No personal data beyond the datasets' own de-identified identifiers, and no credentials or API keys, are included (tracked files were scanned). The Redivis sign-in used to download CheXpert is cached by its client on the training machine, outside the repository.

## Preparation (reproduced by the code)

Patient-level splits with near-duplicate grouping; removal of 170 Kermany patients present in both the official train and test folders; label harmonisation (lung opacity / pneumonia vs normal); CheXpert selection (frontal, adult, one image per patient; positives = Lung Opacity / Pneumonia / Consolidation, negatives = No Finding without uncertain labels). Entry points: `notebooks/01_data.ipynb`, `scripts/chexpert/make_manifest.py`. Details: report §3.
